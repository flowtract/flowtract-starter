# Security

Do not report vulnerabilities through this starter repository.

Use [Flowtract private vulnerability reporting](https://github.com/flowtract/flowtract/security/advisories/new)
and avoid disclosing vulnerability details publicly.

The starter generates local credentials at runtime, binds only to `127.0.0.1`,
contacts no external API, and collects no telemetry or analytics. It is
evaluation material for the `flowtract@0.1.0` developer preview, not a
production deployment template.
